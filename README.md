# Форм-Ресурс М

Корпоративный сайт слесарной мастерской в Подольске. Проект использует Next.js App Router, TypeScript, Tailwind CSS и Lucide. Next.js экспортирует статические страницы в каталог `out`.

## Локальный запуск

Требуется Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Сайт откроется по адресу http://localhost:3000.

```bash
npm run lint
npm run typecheck
npm run build
npm run preview
```

Команда `preview` требует Python 3 и запускает просмотр сборки по адресу http://127.0.0.1:4173. Неизвестные адреса получают страницу сайта `404.html` с кодом HTTP 404. После изменения обработчика перезапустите процесс просмотра.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/app` | Страницы, глобальные стили, метаданные, sitemap и robots |
| `src/components` | Навигация, общие блоки и форма обращения |
| `src/content/site.ts` | Контакты, реквизиты, карта, настройки формы и тексты для публикации |
| `src/content/services.ts` | Описания услуг и материалы для их страниц |
| `src/content/projects.ts` | Портфолио, статусы публикации и показ демонстрационных записей |
| `public/images` | Локальные изображения и карточка Open Graph |

## Наполнение

- Заполните контакты в `src/content/site.ts`. Для скрытия незаполненных блоков установите `showPlaceholders: false`. Карта открывается по ссылке из `contact.mapUrl`.
- Чтобы добавить подтверждённую услугу, внесите запись с уникальным `slug` в `src/content/services.ts` и добавьте её изображение в `public/images`. Страница, список услуг, форма и sitemap обновятся при сборке.
- Для нового кейса создайте запись с уникальным `id` и соответствующим `serviceSlug`. Добавьте описания задачи, работ и результата, пути к фото до и после и выставьте `status: "published"`. Статус `draft` скрывает запись, а `showDemoProjects` управляет видимостью демонстрационных кейсов.
- Технические иллюстрации можно заменить фото мастерской. Обновите путь к файлу и подпись в компоненте страницы. Шаблон поддерживает локальные изображения. Основные шрифты заданы в `globals.css`, при отсутствии IBM Plex на устройстве используется системный стек.
- Чтобы включить форму, задайте подтверждённый `contact.email`, утверждённые `privacy.approvedText` и `privacy.approvedConsent`, затем включите `contact.inquiryEnabled`. Посетитель получит черновик в своей почтовой программе и отправит его там. Для автоматической отправки и приёма файлов потребуется отдельная интеграция.

## Публикация

1. Заполните данные из [CONTENT_CHECKLIST.md](CONTENT_CHECKLIST.md) и проверьте результат в локальной сборке.
2. По образцу `.env.example` создайте `.env.local` или задайте переменные в настройках сборки хостинга. В `SITE_URL` укажите фактический адрес сайта без пути, например `https://form-resurs-m.ru` после регистрации домена. Для тестового сайта оставьте `SITE_INDEXABLE=false`.
3. Для публикации установите `SITE_INDEXABLE=true`. Команда `npm run build` сформирует canonical URL, Open Graph, robots.txt и sitemap.xml для настроенного домена.
4. Разместите содержимое `out` на статическом хостинге. Настройте HTTPS, обслуживание адресов со слешем и отдачу файла `404.html` с кодом HTTP 404.
