# Project Identity

Form-Resurs M is an industrial B2B corporate website. Its visual direction is Industrial Editorial, Precision Engineering and Swiss-inspired minimalism. The website must feel professionally art-directed.

# Design Principles

- Prioritize visual hierarchy, typography and composition.
- Use a consistent modular grid with deliberate whitespace.
- Keep layouts restrained and technically precise. Use asymmetric layouts where justified.
- Vary section composition while maintaining consistency across routes.
- Maintain strong contrast and comfortable readability. Use authentic industrial imagery when available.

# Anti-AI-Slop Rules

Avoid generic SaaS heroes, excessive gradients, glassmorphism, glow, unnecessary rounded cards, repeated three-column feature grids, floating icons, meaningless animation, fake statistics and testimonials, generic marketing copy and exaggerated effects.

# Visual Tokens

- Graphite #171B20
- Accent #B52932
- Warm background #F0EFEB
- Secondary text on dark surfaces #92979B
- White #FFFFFF
- Manrope or IBM Plex Sans for primary typography, IBM Plex Mono for technical labels.

Use consistent spacing, typography and border treatments.

# Component Quality

Use reusable components where appropriate, semantic HTML, visible keyboard focus and stable image dimensions. Keep animation subtle and respect reduced-motion preferences. Avoid unnecessary abstractions and maintain consistency across routes.

# Content Rules

Centralize editable content, distinguish placeholders from verified material, and use only confirmed facts, services, reviews and projects.

# Design Review

Review visual hierarchy, alignment, spacing, type, image proportions, mobile layouts and route consistency. Identify generic compositions and improve them before handoff.

# Development Quality

Use TypeScript and modular components. Run lint, type checks and production build. Test all routes and interactive controls. Report functionality and verification accurately.

Codex must read and follow AGENTS.md before every subsequent substantial change to the project.

## Pre-handoff checks

Review the layout at 320, 375, 768, 1440 and 1920 px. Check horizontal overflow, keyboard navigation, all internal links and the contact form states. Use real workshop photos when approved materials are available. Keep demonstration projects visibly marked and editable from the content files.
